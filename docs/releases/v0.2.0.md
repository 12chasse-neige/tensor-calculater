# Tensor Calculator 0.2.0

This release adds complete LaTeX result copying and improves metric input and
window layout in the native macOS application.

## New and improved

- Copy every stored component of a tensor as a single LaTeX `aligned` block
  from its overview card or component page. Copies include coordinate labels
  and upper/lower index positions, preserve unresolved symbolic zeros, and
  include the complete result even when a search filter is active. Vanishing
  tensors copy an indexed zero equation; scalar cards copy a complete equation.
- Use more of the available window space with expanding metric editor and
  preview panels. Smaller windows stack the preview below the editor.
- Enter elementary functions without declarations, including capitalized
  names such as `Sin(x)` and `COS(x)`, exponential forms `e^x` and `E^x`,
  powers such as `sin^2(x)`, and `arcsin`, `arccos`, and `arctan` aliases.
  Explicitly declared symbols and unknown functions keep their meaning.
- Use `\mathrm{e}` and `\operatorname{exp}` in LaTeX metrics, with consistent
  expression conversion inside `diag(...)`.
- Read clearer function-input errors and updated syntax highlighting and help.
- Copy tensor labels with spacing between upper and lower index groups.

## Download

`Tensor-Calculator-0.2.0-macOS-arm64.zip` contains **Tensor Calculator.app**.
Extract the archive and move the app to your Applications folder.
`SHA256SUMS.txt` contains the archive's SHA-256 checksum.

The binary requires **Apple Silicon and macOS 15 or later**. It runs offline
without Python or Homebrew. The app is signed ad hoc and has not been notarized
by Apple. Source code and build instructions are available in the repository.

## Compatibility

Existing `.tensorcalc` documents and the version-1 worker protocol remain
compatible. The mathematical conventions and symbolic-zero policy are unchanged.
LaTeX result blocks use display math and require `amsmath` for `aligned`.

## Validation

The packaged worker passes 22 independent mathematical and protocol tests.
The release configuration passes 15 native integration tests, including
function input, sign controls, document provenance, cancellation, and layout.
Wide and small window snapshots were inspected, and exported two-sphere tensor
and scalar equations compile with `amsmath`. The bundle passes strict recursive
code-signature verification.
