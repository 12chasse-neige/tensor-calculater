# Tensor Calculator 0.1.0

The first native macOS release of Tensor Calculator replaces the Python
application with a SwiftUI interface and a C++ symbolic calculation engine.

## Features

- Calculate the inverse metric, Christoffel symbols, Riemann and Ricci tensors,
  Ricci scalar, and Kretschmann scalar from a symmetric coordinate metric.
- Enter bracketed matrix rows or LaTeX matrices and see a rendered metric preview.
- Choose the metric signature and either Riemann sign convention.
- Read and copy LaTeX tensor equations with clearly ordered upper and lower indices.
- Start from flat spacetime, Schwarzschild, Reissner–Nordström, Kerr, FLRW,
  or a two-sphere; the selection highlight follows the loaded example.
- Save calculations and their results as `.tensorcalc` documents, search tensor
  components, and cancel calculations.
- Run offline without installing Python or Homebrew.

## Download

`Tensor-Calculator-0.1.0-macOS-arm64.zip` contains the application. Extract the
archive and move **Tensor Calculator.app** to your Applications folder.
`SHA256SUMS.txt` contains the archive's SHA-256 checksum.

This binary requires **Apple Silicon and macOS 15 or later**. The bundle is
signed ad hoc and has not been notarized by Apple. Source code and build
instructions are available in the repository.

## Validation

The release passes 19 independent engine checks and 13 native application
checks. The native checks include rapid preset changes, LaTeX input, sign
conventions, saved documents, cancellation, and formula rendering. Light and
dark appearances and the smaller window layout were inspected in rendered views.

## Calculation scope

The calculation worker accepts 1–8 coordinates and a restricted mathematical
input grammar. Only proven symbolic zeros are omitted. Results apply where the
metric is invertible and its expressions are defined. The Kerr Kretschmann
invariant uses a recognized closed form; other selected tensors are computed
from the metric. See the README for the full conventions and simplification rules.
